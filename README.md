# Taskly

A simple, clean, and interactive Todo List application built with vanilla HTML, CSS, and JavaScript.

Taskly helps users organise their daily tasks, track their progress, and manage completed and pending tasks through a minimal lavender-themed interface.

## Features

- **Add Tasks:** Create new tasks easily.
- **Delete Tasks:** Remove individual tasks.
- **Edit Tasks:** Update existing tasks.
- **Mark as Completed:** Track completed tasks using checkboxes.
- **Task Filters:** View All, Active, or Completed tasks.
- **Clear Completed:** Remove all completed tasks at once.
- **Progress Counters:** Track total, completed, and remaining tasks.
- **LocalStorage:** Tasks remain saved even after refreshing the browser.
- **Input Validation:** Prevents empty or whitespace-only tasks.
- **Keyboard Support:** Press Enter to add a task.

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser LocalStorage API

## Getting Started

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd Taskly
   ```

3. Open `index.html` in your browser.

No additional dependencies or installations are required.
